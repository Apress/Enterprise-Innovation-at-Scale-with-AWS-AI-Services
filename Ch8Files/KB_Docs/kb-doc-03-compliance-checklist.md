# Job Posting Compliance Checklist

Use this checklist before publishing any job posting. All items marked as **REQUIRED** must be completed. Items marked **RECOMMENDED** support best practices.

---

## SECTION A: COMPENSATION & PAY TRANSPARENCY

### A1: Pay Range Disclosure (REQUIRED)

- [ ] Posting includes a specific minimum salary/compensation figure
- [ ] Posting includes a specific maximum salary/compensation figure
- [ ] Range is expressed in clear numbers, not vague terms like "competitive" or "negotiable"
- [ ] Range is prominent and easy to find (not buried in fine print)
- [ ] Range is in format: "$X - $Y per [year/month/hour]" or similar

**Example Pass:**
```
Salary: $85,000 - $120,000 per year
```

**Example Fail:**
```
Competitive salary based on experience
```

### A2: Regional Pay Variation (REQUIRED if applicable)

- [ ] If position is multi-state or multi-region, pay ranges are specified for each region
  - OR
- [ ] A single range covers the position regardless of location (with explanation if needed)

**Example Pass:**
```
Salary range:
- San Francisco Bay Area: $110,000 - $150,000
- Remote (California): $95,000 - $130,000
- Remote (Other US): $85,000 - $120,000
```

### A3: Benefits Transparency (RECOMMENDED)

- [ ] If benefits are mentioned, they are specific (e.g., "health insurance," "401(k) with 4% match")
- [ ] Vague benefit promises are avoided ("unlimited PTO," "as much as possible")
- [ ] Any equity/stock options are clearly described

---

## SECTION B: LANGUAGE & DISCRIMINATION

### B1: Age Discrimination (REQUIRED)

- [ ] No explicitly age-specific language ("young," "digital native," "energetic," "recent grad")
- [ ] No implicit age proxies ("startup culture," "fast-paced," "all-nighters" without justification)
- [ ] Experience requirements focus on skills, not years: "Demonstrated expertise in X" rather than "15+ years required"
- [ ] If years are mentioned, they include alternative paths: "5+ years typical, but equivalent professional experience considered"

**Language to Avoid:**
- "Young and energetic"
- "Digital native"
- "Tech-savvy millennial"
- "Recent graduate preferred"
- "Old school thinking not welcome"

**Better Language:**
- "Motivated professional"
- "Proficient with modern tools"
- "Experienced in current technologies"
- "Skills and experience in X" (focus on competencies, not years)

### B2: Gender Discrimination (REQUIRED)

- [ ] No gendered pronouns ("he/she," "his/her") - use "they" or "the candidate"
- [ ] No gendered job titles ("salesmen," "fireman," "girl") - use neutral terms ("sales professionals," "firefighter," "professional")
- [ ] No stereotypical language ("team player," "aggressive," "nurturing") - focus on specific competencies
- [ ] No appearance or physical attractiveness references

**Language to Avoid:**
- "Salesmen and sales ladies"
- "Needs to be a mother figure to the team"
- "Aggressive negotiators"
- "Looking for an attractive receptionist"

**Better Language:**
- "Sales professionals"
- "Collaborative team members"
- "Strong negotiators"
- "Receptionist"

### B3: Disability & Ableist Language (REQUIRED)

- [ ] No ableist slurs or stigmatizing terms ("crazy," "insane," "lame," "dumb," "OCD" as a joke)
- [ ] No assumptions about disability ("must be able-bodied," "mentally stable," "no disabled candidates")
- [ ] Reasonable accommodation language is included

**Language to Avoid:**
- "Crazy deadlines"
- "Insane hours"
- "Lame excuses won't fly"
- "Wheelchair access not needed"
- "Normal employees only"

**Better Language:**
- "Fast-paced deadlines"
- "Extended hours during peak periods"
- "High accountability expected"
- "Fully accessible facilities including..."
- Use "qualified employees" instead of "normal"

### B4: Race/Ethnicity & National Origin (REQUIRED)

- [ ] No racial or ethnic requirements or preferences
- [ ] No "English-speaking only" (unless truly required for the role)
- [ ] No country-of-origin requirements ("born in US," "US citizen preferred" - citizenship required only if legally mandated)

**Language to Avoid:**
- "White candidates preferred"
- "Must be native English speaker" (unless true job requirement)
- "Requires US citizenship" (unless mandated by law/security clearance)

**Better Language:**
- No race/ethnicity references at all
- "Fluent English communication required" (if truly needed)
- "Must meet visa sponsorship requirements" or "US work authorization required"

### B5: Religion (REQUIRED)

- [ ] No religious requirements or assumptions
- [ ] No references to prayer, church, or religious belief as job functions (unless it's a religious organization role)

**Language to Avoid:**
- "Christian values preferred"
- "Willing to pray at team meetings"
- "Sabbath-unavailable candidates need not apply"

**Better Language:**
- Avoid all religious references unless role-specific
- "Flexible scheduling available"

### B6: Socioeconomic Status (RECOMMENDED)

- [ ] No classist assumptions ("Ivy League only," "must own car" unrelated to driving requirement)
- [ ] No unpaid internships or unpaid trials
- [ ] No credit score or financial requirement unless truly job-related

## SECTION C: JOB FUNCTION & QUALIFICATION CLARITY

### C1: Essential vs. Preferred (REQUIRED)

- [ ] Essential qualifications are clearly marked as such
- [ ] Preferred qualifications are clearly marked and are truly optional
- [ ] Essential qualifications are defensible as truly necessary
- [ ] Preferred qualifications don't deter diverse applicants

**Example Pass:**
```
Essential:
- 3+ years Python development
- SQL database experience

Preferred:
- AWS cloud platform experience
- Agile methodology familiarity
```

### C2: Reasonable Accommodation Language (REQUIRED)

- [ ] Posting includes equal opportunity/EEO statement
- [ ] Posting explicitly mentions reasonable accommodations availability
- [ ] Contact method for accommodation requests is provided

**Required Language:**
```
[Company] is an Equal Opportunity Employer. We are committed to building
a diverse team and provide reasonable accommodations for qualified
individuals with disabilities. If you need an accommodation to apply,
please contact [HR contact info].
```

### C3: Job Location & Remote Status (REQUIRED)

- [ ] Location is clearly specified (city/state/remote/hybrid)
- [ ] If remote, the geographic restrictions (if any) are stated
- [ ] If hybrid, the frequency and location of in-office work is specified
- [ ] If travel is required, frequency is stated

**Example Pass:**
```
Location: San Francisco (hybrid; 2 days/week in office)
```

**Example Fail:**
```
Location: TBD
```

### C4: Physical Requirements (if applicable) (REQUIRED)

- [ ] Any physical requirements are truly essential and job-related
- [ ] Requirements are stated with accommodation options
- [ ] Lifting/mobility requirements are specific ("lift up to 50 lbs regularly")

**Example Pass:**
```
Essential Functions: Lifting inventory boxes (up to 50 lbs) up to 20 times
per shift. Reasonable accommodations available for qualified individuals.
```

**Example Fail:**
```
Must be physically fit and able-bodied.
```

---

## SECTION D: HARMFUL JARGON & CODED LANGUAGE

### D1: Industry Jargon (REQUIRED)

- [ ] No pseudo-compliment jargon that's actually coded for youth ("rockstar," "ninja," "guru," "unicorn")
- [ ] No startup-culture jargon that implies unsustainable hours ("disruption," "moving fast and breaking things")

**Language to Avoid:**
- "We're looking for a rockstar developer"
- "Ninja-level JavaScript skills"
- "Guru in cloud architecture"
- "Move fast and break things"
- "Hustle culture mentality"

**Better Language:**
- "Expert-level developer"
- "Advanced JavaScript proficiency"
- "Senior expertise in cloud architecture"
- "Delivers results efficiently and thoughtfully"
- "Ambitious professional seeking growth"

### D2: Vague Culture Language (RECOMMENDED)

- [ ] Avoid vague culture statements ("we're a family," "drinks with team are required," "live, breathe, sleep the job")
- [ ] Specify actual benefits instead of cultural claims
- [ ] Be honest about work-life balance expectations

**Language to Avoid:**
- "We're a family"
- "Work hard, play hard"
- "Live and breathe our mission"
- "Social events mandatory"

**Better Language:**
- "Collaborative team environment"
- "Flexible work arrangements"
- "Competitive compensation and benefits"
- "Optional team social events"

---

## SECTION E: ACCESSIBILITY & FORMATTING

### E1: Visual Accessibility (REQUIRED)

- [ ] Font size is readable (11pt or larger)
- [ ] Text color provides sufficient contrast with background
- [ ] No all-caps text for extended passages (hard to read)
- [ ] Adequate spacing between sections

### E2: Structure & Readability (REQUIRED)

- [ ] Clear headings divide the posting into logical sections
- [ ] No walls of unbroken text (use bullet points)
- [ ] Lists are formatted with bullets or numbers
- [ ] Important information (salary, location) is easy to spot

### E3: Screen Reader Compatibility (RECOMMENDED)

- [ ] Images have alt text describing content
- [ ] No critical information conveyed only through color
- [ ] Headings follow proper hierarchy (H1, H2, H3)

---

## SECTION F: LEGAL & REGULATORY COMPLIANCE

### F1: California (SB 1162) (REQUIRED if posting to California)

- [ ] Pay range disclosed (minimum and maximum)
- [ ] Range is specific numbers, not vague terms
- [ ] Applies to ALL positions advertised in California or to California residents

### F2: Equal Employment Opportunity (REQUIRED)

- [ ] No discrimination on basis of protected class (age, race, color, religion, gender, national origin, disability, veteran status, genetic info)
- [ ] No requirement for protected class status
- [ ] Language is inclusive and welcoming

### F3: ADA Compliance (REQUIRED)

- [ ] Reasonable accommodation language included
- [ ] No exclusion of individuals with disabilities
- [ ] Essential functions clearly defined (may require accommodations)
- [ ] Contact information for accommodation requests provided

### F4: Title VII & EEOC (REQUIRED)

- [ ] No reference to race, color, or national origin
- [ ] No gender-specific language
- [ ] No religious requirements

---

## SECTION G: CHECKLIST SUMMARY

### Critical Pass/Fail Items (ALL MUST PASS)

- [ ] Pay range disclosed if posting in California (required by law)
- [ ] No explicitly age-biased language
- [ ] No explicitly gender-biased language
- [ ] No explicitly ableist language
- [ ] No racial or ethnic discrimination
- [ ] Reasonable accommodation language included
- [ ] Essential vs. preferred qualifications clear
- [ ] Location/remote status specified
- [ ] At least readable font and basic formatting
- [ ] No illegal discrimination based on protected class

## DECISION TREE

**1. Is this posting for California?**
   - YES → Add pay range (REQUIRED)
   - NO → Proceed to Q2

**2. Does posting use age-coded language?** (young, digital native, recent grad, startup culture, all-nighters, rockstar, ninja)
   - YES → Revise (REQUIRED)
   - NO → Proceed to Q3

**3. Does posting use gender language?** (he/she, gendered job titles, stereotypes)
   - YES → Revise (REQUIRED)
   - NO → Proceed to Q4

**4. Does posting use ableist language?** (crazy, insane, lame, dumb, "normal" employees)
   - YES → Revise (REQUIRED)
   - NO → Proceed to Q5

**5. Is reasonable accommodation language included?**
   - YES → Proceed to Q6
   - NO → Add EEO + accommodation language (REQUIRED)

**6. Are qualifications clearly marked as essential vs. preferred?**
   - YES → Proceed to approval
   - NO → Clarify before posting

**If ANY required item fails, do not post. Revise and re-check.**

---

## ESCALATION TRIGGERS

**Route to HR Legal if:**
- Posting contains any language flagged as "REQUIRED" that fails
- You're unsure about a qualification's necessity
- Job has unusual or complex requirements
- You're posting a role in multiple states with different laws
- Posting touches on protected class issues

---

## BEFORE YOU POST

1. Hiring manager has approved
2. All REQUIRED items are checked
3. Posting has been reviewed for tone (is it welcoming?)
4. You're ready to commit to the salary range posted
5. Posting is saved with version date for records
